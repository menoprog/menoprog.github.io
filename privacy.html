개인정보처리방침

뇌스낵 업로더 · 시행일 2026년 9월 30일

「뇌스낵 업로더」(이하 "이 앱")는 유튜브 채널 「뇌스낵」의 운영자가 자기 채널에 영상을 올리기 위해 직접 만들어 쓰는 도구입니다. 이 방침은 이 앱이 Google 사용자 데이터를 어떻게 접근·이용·보관·공유하는지 설명합니다.

1. 접근하는 Google 데이터

이 앱은 채널 운영자 본인의 Google 계정 승인을 받아 YouTube Data API 를 다음 범위(scope)로 사용합니다.

  • youtube.upload : 운영자 채널에 영상을 업로드하고 제목·설명·예약 공개 시각을 설정합니다.
  • youtube.force-ssl : 업로드한 영상의 공개 상태를 확인하고, 운영자 명의로 댓글을 작성합니다.

운영자 본인 채널 외의 계정, 채널, 영상, 시청자 정보에는 접근하지 않습니다. 시청자의 개인정보는 어떤 것도 수집하지 않습니다.

2. 이용 목적

위 데이터는 오직 (1) 영상 업로드, (2) 업로드 상태 확인, (3) 해당 영상에 질문 댓글 작성에만 사용합니다. 광고, 프로파일링, 분석, 인공지능 모델 학습 등 다른 목적에는 쓰지 않습니다.

3. 보관과 보안

  • Google 이 발급한 OAuth 토큰은 운영자의 개인 컴퓨터에만 저장되며, 파일 권한은 운영자 계정만 읽을 수 있도록 제한합니다.
  • 업로드 결과(영상 ID, 예약 시각, 댓글 ID)는 같은 컴퓨터의 로컬 파일에 기록합니다.
  • 외부 서버나 클라우드 저장소로 Google 데이터를 전송하거나 보관하지 않습니다.

4. 제3자 제공

Google 사용자 데이터를 제3자에게 판매, 제공, 공유하지 않습니다. 영상 제작에 쓰는 이미지·음성 생성 서비스에는 대본 문장과 이미지 프롬프트만 전달되며, Google 계정 데이터는 전달되지 않습니다.

5. Limited Use 준수

이 앱이 Google API 로 얻은 정보의 이용과 다른 앱으로의 이전은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 따릅니다.

6. 권한 철회와 삭제

운영자는 언제든 Google 계정 권한 관리에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 유효하지 않으며, 로컬에 남은 토큰 파일은 즉시 삭제합니다.
